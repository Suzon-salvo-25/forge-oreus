# FORGE par Oréus

Questionnaire personnalisé qui prépare, en quelques clics, le cahier des charges d'un premier agent IA Oréus.
Chaque organisation reçoit par e-mail un code d'accès qui ouvre sa fiche préremplie (sources publiques).

- Conçu par Lola ; intégré au Launchpad Oréus.
- Les fiches sont chiffrées dans la page (PBKDF2-SHA256 + AES-256-GCM) : sans le code, elles sont illisibles.
- Page générée automatiquement depuis le dépôt du projet (`site/forge_build.py`) : ne pas modifier `index.html` à la main.
